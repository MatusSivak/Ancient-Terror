# November 3 source recordings

Retained CC0 recordings for the November bug-report audio improvements.
Authors, exact download URLs, runtime mappings and processing instructions are in
[NOV3_AUDIO.md](../../../assets/sounds/NOV3_AUDIO.md).

`om.mp3` is Freesound's HQ preview of ApeironMedia's Om.wav.
`register.wav` is Slap Alert's excerpt of Tompalompa's vintage register recording.
The three OGG files are JaggedStone's original spell recordings. `swishes.zip`
is artisticdude's original archive; only swish-7 and swish-10 are used.
